# AGENTS.md

Laravel 13 (Inertia + React 19 + Vite 8 + Tailwind 4) app that hosts a TCG prototype: a hot-seat card match at `/match` driven by a pure-TS rules engine. No README. Reference docs: `docs/game-rules.md` (rules source of truth), `TODO/TCG_PROJECT_ROADMAP.md`, `TODO/CARD_SHADER_DESIGN_GUIDE.md`.

## Commands

- **Frontend tests:** `npm test` (Vitest, node env, only `resources/js/**/*.test.ts`). Focused: `npx vitest run resources/js/lib/game/engine.test.ts`.
- **Backend tests:** `php artisan test` (PHPUnit, SQLite `:memory:`).
- **Full CI gate:** `composer ci:check` (eslint, prettier, tsc, phpstan, pint, PHPUnit). Run this before finishing work.
- **Non-destructive checks:** `npm run lint:check`, `npm run format:check`, `npm run types:check` (tsc --noEmit), `composer lint:check` (pint --test), `composer types:check` (phpstan, level 7, covers `app/ bootstrap/ config/ database/ routes/`).
- `npm run lint` and `npm run format` auto-fix/write files; use the `*:check` variants unless you intend to rewrite.
- Use **npm**, not pnpm (package-lock.json is the lockfile; `pnpm-workspace.yaml` is vestigial). `.npmrc` sets `ignore-scripts=true`, so packages relying on postinstall scripts won't run them.

## Setup

- **Game data is not seeded automatically.** `DatabaseSeeder` only creates a test user; `composer setup` migrates but never seeds cards. Run `php artisan db:seed --class=GameDataSeeder` to load sets, factions, cards, and leaders.
- `/match` is behind `auth` + `verified` middleware. Seeded login: `test@example.com`.
- `.env` and `database/database.sqlite` are gitignored — a fresh clone needs `composer setup` before anything works.

## Subdirectory deployment (biggest gotcha)

The app is served by nginx under `/tcg-cosmos/public` (not the domain root); `APP_URL` is `http://localhost:3000/tcg-cosmos/public`. Wayfinder generates root-relative route URLs, so a custom Vite plugin (`tcg-wayfinder-prefix` in `vite.config.ts`) rewrites generated files (`resources/js/routes/**`, `resources/js/actions/**`) at build start to prefix every route URL with `/tcg-cosmos/public`. Those directories are gitignored and regenerated by the Wayfinder Vite plugin on every `npm run build`/`npm run dev` — never hand-edit them, and after `php artisan wayfinder:generate` you must run `npm run build` to re-apply the prefix or links 404.

## Card data flow & schemas

- Cards are seeded in `database/seeders/GameDataSeeder.php`, served by `MatchController@index` as `CardDef[]`, then merged with `TOKEN_CARDS` in `resources/js/lib/game/library.ts` via `buildLibrary()`.
- Adding a card = edit the seeder + re-seed. Adding a **summon** effect (`defId`) also requires a token entry in `TOKEN_CARDS` — summoned tokens are not in the DB and the engine throws "Unknown card" without them.
- **Effects schema mismatch (current bug):** the seeder stores effects flat (`[['kind'=>'damage','target'=>'target_unit','scope'=>'enemy_unit']]`) and `MatchController` passes them through raw, but the engine's `resolveEffects` (engine.ts) and `cardTargetScope` expect `CardEffect[]` = `[{trigger:'on_play', actions:[{kind, target:{kind:'target_unit', scope}}]}]`. As wired today, card effects (and target scopes) silently do nothing in the running match; `engine.test.ts` constructs the correct shape manually. Reconcile this when doing effects work.
- Starter decks are auto-built by `buildStarterDeck`: faction leader + 3 copies of the cheapest faction/neutral cards until 30. Deck rules in `docs/game-rules.md` (30 cards, 3-copy limit, board limit 6, leader 30 HP).

## Style
